Force-aware Vision-Language-Action (VLA) policies improve contact-rich manipulation by conditioning action generation on interaction feedback~\cite{yu2025forcevlaenhancingvlamodels,li2026forcevla2unleashinghybridforceposition,zhang2025tavlaelucidatingdesignspace}. Yet they typically represent nominal task motion and contact-dependent adjustment within the same generative action prediction. At deployment, nominal motion can be reused across nearby control cycles, whereas physical correction should adapt to newly observed contact. This coupling leaves the correction without an explicit supervision target or an independently executable output.

A natural factorization is to combine a task-level reference with an additive force-responsive residual. This form exposes a directly executable pose-space update while preserving the teacher's nominal task motion. Learning the factorization from offline demonstrations is nevertheless underdetermined: demonstrations provide executed actions but no labels assigning behavior to the reference or residual. Direct action supervision therefore admits decompositions in which the reference retains contact-dependent behavior or the residual reproduces nominal motion.

Subtracting a cached reference from the demonstrated action mixes physical correction with reference staleness. A zero-force query represents a valid physical state rather than missing force conditioning. These ambiguities motivate constructing an explicit correction target from a pretrained force-aware policy and its existing offline data.

Fast--slow and asynchronous systems determine \emph{when} physical information is refreshed~\cite{li2026favlaforceadaptivefastslowvla,wang2026lateforceacceleratingvla,vanjani2026damvladecoupledasynchronousmultimodal}. Residual reinforcement learning and corrective imitation learning define \emph{what} a corrective branch predicts through task rewards or additional on-policy corrections~\cite{ankile2024imitationrefinementresidual,xu2025compliantresidualdaggerimproving}. Our setting derives this target from an offline force-aware teacher. Deployment then updates the correction independently of the generative reference policy while reusing semantic context and compensating for stale references.

We introduce \emph{null-mode residual distillation}. First, a learned null-force operating point and matched-noise full/null teacher queries identify a teacher-defined force-conditioning correction target. Second, a complementary staleness target compensates for the cache-age discrepancy between the reference and current prediction. Third, an independently executable residual pathway reuses cached task context and timestamped null-mode references while updating pose corrections from recent force history, decoupled from the teacher's generative action inference.

The contributions of this work are:
\begin{enumerate}
    \item We formulate force-responsive policy decomposition as a teacher-distillation problem and introduce \textbf{null-mode residual distillation}. A learned null-force operating mode and matched-noise teacher queries provide explicit correction targets without task rewards or additional corrective or on-policy demonstrations;
    \item We introduce \textbf{staleness-aware residual distillation} for asynchronous reference execution, learning stale-reference compensation under replayed deployment schedules to keep the distilled correction valid as the cached reference ages; and
    \item We develop an \textbf{independently executable residual pathway} that reuses cached task context and timestamped null-mode references while updating force-responsive pose corrections asynchronously from the generative VLA.
\end{enumerate}
