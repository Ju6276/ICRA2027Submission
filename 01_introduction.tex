Vision-Language-Action (VLA) models provide semantic generalization for robot manipulation, yet contact-rich tasks demand feedback that is both physically informative and temporally responsive. Visual observations may not reveal contact onset, slip, impact, or constrained motion, whereas force/torque measurements directly characterize these interaction states. Force-aware VLAs therefore condition action generation on force/torque feedback~\cite{yu2025forcevla,li2026forcevla2,zhang2025tavla}. However, incorporating a newly observed force measurement still requires another complete action prediction, even when physical interaction calls only for a local correction.

Recent slow--fast architectures reuse visual--language context in a force-responsive pathway~\cite{li2026favla,lv2026lift}. The fast pathway, however, remains a complete-action predictor: each update re-synthesizes nominal motion already represented by the slow policy together with any force-induced change. Caching the prefix avoids repeating visual--language encoding, but not action generation, and rate separation alone does not specify which part of the action belongs to the reactive branch.

A residual formulation separates these roles by composing a slowly updated reference with a force-conditioned correction. The central challenge is to identify the correction from offline demonstrations: each demonstration supervises only the executed action, not its decomposition into reference and residual components. Direct behavior cloning therefore admits degenerate decompositions in which the slow branch retains contact-dependent behavior or the fast branch reproduces the nominal policy. An explicit residual target is required to specialize the reactive pathway.

We address this problem with \emph{null-mode residual distillation}. A force-aware VLA teacher is queried twice on the same observation after teacher training is complete. The paired queries share the image, instruction, robot state, visual--language prefix, and initial flow noise; one uses the measured force history and the other uses an adapted null-force mode. Their pose difference defines the correction target, while the null-mode prediction provides the reference. A compact causal student distills this target from the latest force history, cached task context, robot state, and current reference, enabling asynchronous correction without rerunning the generative action expert.

The contributions of this work are:
\begin{enumerate}
    \item \textbf{Null-mode residual distillation}, an offline objective that derives explicit action-space correction targets from a pretrained force-aware VLA by differencing its factual-force and null-force modes, without task rewards or additional corrective demonstrations;
    \item \textbf{A learned null-force reference mode} that jointly optimizes a null token and a mode-specific adapter, and couples factual and null predictions through a shared visual--language prefix and initial flow noise to obtain a stable model-level conditional difference; and
    \item \textbf{A slow--fast policy factorization} in which the VLA teacher generates semantic reference actions, while a compact residual policy asynchronously predicts force-conditioned pose corrections without repeated generative action inference.
\end{enumerate}
