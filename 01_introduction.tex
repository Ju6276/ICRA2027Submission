Vision-Language-Action (VLA) models provide semantic generalization for robot manipulation, yet contact-rich tasks demand feedback that is both physically informative and temporally responsive. Visual observations may not reveal contact onset, slip, impact, or constrained motion, whereas force/torque measurements directly characterize these interaction states. Force-aware VLAs therefore condition action generation on force/torque feedback~\cite{yu2025forcevla,li2026forcevla2,zhang2025tavla}. Their response rate, however, remains limited when every force update invokes multimodal inference and iterative action generation.

Recent slow--fast architectures reduce this cost by reusing visual--language context in a force-responsive pathway~\cite{li2026favla,lv2026lift}. Nevertheless, the fast pathway is generally optimized to regenerate complete actions, including nominal motion already represented by the slow policy. This coupling makes the computational cost of physical feedback depend on the full action generator rather than on the complexity of the required correction.

A residual formulation separates these roles by composing a slowly updated reference with a force-conditioned correction. The central challenge is to identify the correction from offline demonstrations: each demonstration supervises only the executed action, not its decomposition into reference and residual components. Direct behavior cloning therefore admits degenerate decompositions in which the slow branch retains contact-dependent behavior or the fast branch reproduces the nominal policy. An explicit residual target is required to specialize the reactive pathway.

We address this problem with \emph{counterfactual residual distillation}. A frozen force-aware VLA teacher is evaluated on paired inputs that share the image, instruction, robot state, visual--language prefix, and flow noise, but differ in whether measured force history or an adapted null-force condition is supplied. The difference between the paired predictions defines the correction target, while the null-conditioned prediction provides the slow reference. A compact causal student distills this target from force history and cached task context, enabling asynchronous residual updates without rerunning the generative action expert.

To accommodate variations in slow-policy rate and inference latency, training exposes the student to randomized context age and scheduling jitter. At deployment, the teacher periodically refreshes the reference and task context, while the student updates only the pose correction from the latest force measurements.

The contributions of this work are:
\begin{enumerate}
    \item \textbf{Counterfactual residual distillation}, which converts paired factual-force and null-force predictions of a frozen VLA teacher into an explicit supervision signal for force-responsive correction;
    \item \textbf{An adapted null-force teacher mode} coupled to the factual query through a shared visual--language prefix and shared flow noise, providing both a controlled counterfactual baseline and the slow reference without training a separate nominal policy; and
    \item \textbf{A residual-only force-reactive VLA architecture}, in which a compact causal student updates only the pose correction and avoids iterative full-action generation in the reactive pathway.
\end{enumerate}
