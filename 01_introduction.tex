Vision-Language-Action (VLA) models have shown strong potential for general-purpose robotic manipulation, yet contact-rich tasks remain difficult because vision does not directly reveal interaction force, incipient slip, impact, or contact stability. Force-aware VLAs address this limitation by incorporating force/torque or tactile observations into action generation~\cite{yu2025forcevla,li2026forcevla2,huang2026tafvla}. In these systems, real physical feedback is available to the policy and is essential for precise, safe interaction.

Providing force as an input does not by itself guarantee timely reaction. Visual--language inference is comparatively expensive, whereas force can change within a control cycle. A now-standard response is to split the policy by rate: a slow vision--language backbone updates a reusable context at low frequency, and a fast branch consumes that cached context together with the newest force measurements~\cite{xue2025rdp,li2026favla,vanjani2026damvla,li2026atvla,niu2026trex,wang2026phaforce,lv2026lift,fisvla2025}. This design is sound, and we adopt its deployment structure.

Its fast branch, however, is still a full action generator. FAVLA re-runs the $\pi_0$ action expert against the cached key/value context~\cite{li2026favla,black2024pi0}, and LIFT refreshes a reactive action expert within the chunk against a cached vision-language prefix~\cite{lv2026lift}. Caching removes the vision-language forward pass but not the action-generation cost: every high-rate update still pays a complete flow-matching denoise. We measure this directly. With the prefix already cached, one action-expert forward takes $7.6$~ms on an RTX~4090, so the ten denoising steps of a standard $\pi_0$ sampler cost $76$~ms, or $13$~Hz --- consistent with the $15$~Hz that ForceVLA2 reports on the same GPU class~\cite{li2026forcevla2}. A single forward already consumes $76\%$ of a $100$~Hz budget. The gap to a $100$--$1000$~Hz force sensor is therefore not an implementation detail; it is structural.

Our starting observation is that the high-rate branch never needed to reproduce the action. If the command is written as a reference plus a correction, only the correction has to be recomputed when new force arrives; the reference changes on the semantic timescale and can be interpolated from the last slow update. The correction is a much smaller object than a full action chunk, so a much smaller network should suffice --- provided it can be supervised. Demonstrations, however, contain only the total action and synchronized force, never a label for its force-attributable part. Training both branches against the same total action leaves the split underdetermined: the reference can absorb contact-dependent behavior while the fast branch redundantly reproduces nominal motion.

We construct the missing label from a frozen teacher. A temporal force-aware teacher is first trained on synchronized vision, language, state, and native-rate force history. It is then queried twice for the same observation, once with the measured force history and once with a learned null-force condition, and the difference of the two outputs is the deviation attributable to force conditioning. Two choices make this difference meaningful rather than incidental. First, both queries share the vision-language prefix \emph{and} the flow-matching noise, so the force condition is the only difference between the samples; with independent noise the difference would be dominated by sampling variance. Second, the null condition is a learned token adapted on the frozen teacher, not a zero-padded input, so the null branch remains a competent force-free policy instead of an out-of-distribution collapse whose deviation would measure model breakage rather than force. The teacher's null-conditioned chunk doubles as the slow reference, so no separate nominal policy has to be distilled.

The resulting student is a causal force encoder followed by a single attention block that emits a short chunk of pose corrections: $44.7$~M parameters and one deterministic forward pass, measured at $2.4$~ms ($417$~Hz), a $31.8\times$ reduction of the high-rate path. Because the teacher's update period, inference latency, and jitter are randomized when the targets are generated, and the student is told the measured age of its cached context, one trained student is deployable across slow-branch rates and latencies it never saw --- in contrast to pipelines that fix the rate ratio, or that downsample all modalities to a common training rate.

Differencing a model under a removed condition is not new in itself. Classifier-free guidance forms exactly this difference at inference time~\cite{ho2022cfg}, and guidance distillation compresses the guided \emph{combination} into a cheaper student~\cite{meng2023guidancedistill}. In embodied settings, counterfactual modality interventions have been used to explain which modality drives a prediction~\cite{cma2026modality,embodiedinterp2026}, to deconfound a visual shortcut~\cite{cofactvla2026}, and to reweight actions at test time~\cite{idr2026causal}. All of these use the difference to interpret, debias, or adjust a single model at a single rate. Our claim is a different use: the difference is a \emph{supervision target that factorizes a policy across time scales}, and it is what allows the high-rate path to shrink by an order of magnitude.

Our contributions are:
\begin{enumerate}
    \item the observation, and its measured consequence, that a force-aware policy can be decomposed by \emph{attribution} rather than by architecture: supervising the high-rate branch with the teacher's force-attributable deviation instead of the full action reduces that branch from $76$~ms to $2.4$~ms per update, moving reactive control from $13$~Hz to the force-sensor rate;
    \item a well-posed counterfactual construction for this target --- a learned null-force condition adapted on a frozen teacher, queried under a shared prefix and shared flow-matching noise --- which isolates the force condition from sampling noise and from the distribution shift that zero-padded interventions incur;
    \item a rate-agnostic asynchronous training scheme in which the slow update period, inference latency, and jitter are randomized while generating targets and the student is conditioned on its measured context age, so that one student transfers across deployment rates.
\end{enumerate}

We report the latency analysis and the offline decomposition diagnostics in Sec.~\ref{sec:experiment}. Task-level claims, and in particular whether executing at $100$~Hz rather than $30$~Hz improves contact outcomes, are deferred to the robot evaluation; we state the criteria under which our decomposition would be refuted.
