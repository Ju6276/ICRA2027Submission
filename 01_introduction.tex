Vision-Language-Action (VLA) models provide semantic generalization for robot manipulation, yet contact-rich tasks demand feedback that is both physically informative and temporally responsive. Visual observations may not reveal contact onset, slip, impact, or constrained motion, whereas force/torque measurements directly characterize these interaction states. Force-aware VLAs therefore condition action generation on force/torque feedback~\cite{yu2025forcevla,li2026forcevla2,zhang2025tavla}. The remaining bottleneck is that a newly observed force measurement is still bound to regeneration of a complete action chunk, so the cost of physical feedback follows the full generator rather than the correction that force actually requires.

Recent slow--fast architectures reduce the perception cost by reusing visual--language context in a force-responsive pathway~\cite{li2026favla,lv2026lift}. The fast pathway, however, remains a complete-action predictor: each update re-synthesizes nominal motion already represented by the slow policy together with any force-induced change. Caching the prefix therefore removes vision--language inference, but not action generation, and rate separation alone does not specify which part of the action belongs to the reactive branch.

A residual formulation separates these roles by composing a slowly updated reference with a force-conditioned correction. The central challenge is to identify the correction from offline demonstrations: each demonstration supervises only the executed action, not its decomposition into reference and residual components. Direct behavior cloning therefore admits degenerate decompositions in which the slow branch retains contact-dependent behavior or the fast branch reproduces the nominal policy. An explicit residual target is required to specialize the reactive pathway.

We address this problem with \emph{counterfactual residual distillation}. A force-aware VLA teacher is queried twice on the same observation after teacher training is complete. The paired queries share the image, instruction, robot state, visual--language prefix, and initial flow noise; one uses the measured force history and the other uses an adapted null-force mode. Their pose difference defines the correction target, while the null-mode prediction provides the reference. A compact causal student distills this target from native-rate force history, cached task context, robot state, and the current reference, enabling asynchronous correction without rerunning the generative action expert.

The contributions of this work are:
\begin{enumerate}
    \item \textbf{Counterfactual residual distillation}, which converts paired factual-force and null-force predictions of a frozen VLA teacher into an explicit supervision signal for force-responsive correction;
    \item \textbf{A controlled counterfactual query}, in which a jointly learned null token and null-specific adapter define a valid reference mode, while a shared visual--language prefix and shared flow noise reduce variation unrelated to the conditioning mode; and
    \item \textbf{A residual-only reactive pathway} that updates pose corrections asynchronously from native-rate force, rather than iteratively regenerating complete actions.
\end{enumerate}
