Vision-Language-Action (VLA) models combine semantic perception, language-conditioned reasoning, and visuomotor control within a unified policy. Contact-rich manipulation additionally requires timely access to interaction states that are weakly observable from images, including contact onset, impact, load, and constrained motion. Force-aware VLAs address this limitation by conditioning action generation on force/torque feedback~\cite{yu2025forcevla,li2026forcevla2,zhang2025tavla}. Their force response, however, remains coupled to complete action generation: a new force observation triggers another prediction of both the task-level motion and the contact-dependent adjustment.

Fast--slow and asynchronous architectures address this timing mismatch by decoupling semantic computation, modality refresh, and action updates~\cite{li2026favla,lv2026lift,vanjani2026damvla}. Our focus is complementary to this systems-level separation: how to derive an explicitly supervised additive correction that can execute independently of full-action generation. Reusing visual--language context can reduce repeated semantic computation, but it does not by itself identify which part of a demonstrated action should be assigned to a corrective branch.

An additive residual policy provides the required functional separation: a reference policy represents task-level motion, while a reactive policy predicts only the correction demanded by current interaction. Learning this decomposition from offline demonstrations is underdetermined because the data contain executed actions but no labels assigning behavior to the reference and residual components. Supervising both components with the demonstrated action therefore does not identify the desired correction. The central problem addressed in this work is how to derive explicit force-responsive residual targets from an existing force-aware VLA, using only its original offline demonstrations.

We introduce \emph{null-mode residual distillation}. A force-conditioned VLA is first trained with causal force history and then frozen. We equip the teacher with a learned null-force mode that produces reference actions without instance-specific force input. For matched observations and flow noise, the difference between full-force and null-force predictions defines an action-space target for force-conditioned correction. A second target accounts for the displacement accumulated while an asynchronously generated reference becomes stale. These targets are distilled into a compact residual policy that consumes recent force history and cached task context, and updates pose corrections independently of the teacher's generative action inference.

The contributions of this work are:
\begin{enumerate}
    \item We formulate force-responsive policy decomposition as a teacher-distillation problem and introduce \textbf{null-mode residual distillation}, which constructs explicit action-space correction targets from matched full-force and learned null-force predictions without rewards or corrective demonstrations;
    \item We introduce a \textbf{learned null-force teacher mode}, jointly parameterized by a null token and a mode-specific adapter, that provides an action reference suitable for paired differencing while preserving the pretrained force-conditioned teacher; and
    \item We introduce \textbf{staleness-aware residual distillation}, which jointly supervises force-conditioned correction and the displacement induced by an outdated reference, enabling a compact residual policy to update pose commands independently of full-action generation.
\end{enumerate}
