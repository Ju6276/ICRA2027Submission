Force-aware Vision-Language-Action (VLA) policies improve contact-rich manipulation by conditioning action generation on interaction feedback~\cite{yu2025forcevlaenhancingvlamodels,li2026forcevla2unleashinghybridforceposition,zhang2025tavlaelucidatingdesignspace}. Yet they typically represent task-level motion and contact-dependent adjustment within the same generative action prediction. At deployment, task-level behavior can be reused across nearby control cycles, whereas physical correction should adapt to newly observed contact. This coupling leaves the correction without an explicit supervision target or an independently executable output (Fig.~\ref{fig:teaser}).

An additive residual can retain a base action while exposing a pose-space correction, but offline demonstrations record only the executed action. Multiple base-action--correction splits can reconstruct the same label, and directly subtracting a cached base action further mixes force-conditioned change with base-action delay. Moreover, a measured zero wrench is a valid contact condition, distinct from withholding the wrench history. These ambiguities motivate constructing correction supervision from matched queries of a frozen teacher.

Existing asynchronous policies separate computation or sensor-update rates~\cite{li2026favlaforceadaptivefastslowvla,wang2026lateforceacceleratingvla,vanjani2026damvladecoupledasynchronousmultimodal}. Residual reinforcement learning and corrective imitation obtain the correction signal from rewards or extra on-policy interaction~\cite{ankile2024imitationrefinementresidual,xu2025compliantresidualdaggerimproving}. We instead construct the supervision offline and keep asynchronous execution.

ForceDelta-VLA constructs both learned targets from the cached context available to the fast pathway. Matched force-conditioned and force-agnostic teacher queries share a visual--language prefix and flow noise; their action difference supervises the force correction, while a second state-consistent target captures the remaining discrepancy between the cached base action and cached-context force-agnostic prediction in a common action coordinate system. The learned corrections execute independently of generative inference.

We evaluate ForceDelta-VLA on five single-arm and four bimanual real-robot tasks spanning contact establishment, precision insertion, friction-dominated motion, and constrained manipulation. The proposed method achieves an $82.2\%$ mean success rate, compared with $54.4\%$ for ForceVLA, $57.2\%$ for TA-VLA, and $45.0\%$ for ImplicitRDP. Relative to ForceVLA, it reduces mean successful-trial peak contact force by approximately $26\%$ on both platforms.

The contributions of this work are:
\begin{enumerate}
    \item We introduce \textbf{force-agnostic correction distillation}: an explicit teacher-defined force-correction target from matched force-conditioned and learned force-agnostic predictions of a frozen teacher, using only the original offline dataset;
    \item We formulate a \textbf{state-consistent dual-correction decomposition} that separately supervises force correction and the complete cached base-action discrepancy in a common action coordinate system; and
    \item We develop an \textbf{independently executable correction pathway} that updates pose corrections from recent force history while reusing cached task context and base actions.
\end{enumerate}
