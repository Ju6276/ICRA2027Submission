Vision-Language-Action (VLA) models have shown strong potential for general-purpose robotic manipulation, yet contact-rich tasks remain difficult because vision does not directly reveal interaction force, incipient slip, impact, or contact stability. Force-aware VLAs address this limitation by incorporating force/torque or tactile observations into action generation~\cite{yu2025forcevla,li2026forcevla2,huang2026tafvla}. In these systems, real physical feedback is available to the policy and is essential for precise, safe interaction.

Providing force as an input does not by itself guarantee timely reaction. Visual--language inference and action-chunk generation are comparatively expensive, whereas force changes can require correction within a control cycle. Reactive Diffusion Policy, FAVLA, DAM-VLA, AT-VLA, T-Rex, and PhaForce therefore exploit hierarchical, asynchronous, or slow--fast processing to preserve high-frequency physical feedback~\cite{xue2025rdp,li2026favla,vanjani2026damvla,li2026atvla,niu2026trex,wang2026phaforce}. These methods establish the value of fast force/tactile pathways, but leave a distinct supervision question: \emph{what behavior should the fast pathway learn?}

Suppose the commanded action is written as a nominal reference plus a force-conditioned correction. Demonstrations provide the total action and synchronized force measurements, but not separate labels for the two terms. Training both branches only from the total action therefore leaves the decomposition underdetermined: the nominal policy can absorb contact-dependent behavior, while the fast branch can redundantly reproduce nominal motion. Architectural separation determines where and when force is processed, but does not explicitly supervise the behavioral responsibility of each branch.

We introduce \emph{FoRe-VLA}, a teacher-guided framework for distilling force-conditioned residuals. We first train a temporal force-aware VLA teacher using visual observations, language, robot state, and native-rate force history. The frozen teacher is then queried twice for the same visual--language--state context: once with the measured force history and once with a learned null-force token. The null-conditioned prediction serves as a reference that does not receive the current force measurement. Subtracting it from the full-force prediction yields a force-conditioned policy residual. This operation is paired teacher output differencing; it neither uses a contrastive objective nor assumes that the difference is a causal force effect.

The two teacher-derived targets are distilled into a slow vision--language--state student and a lightweight fast force-conditioned student. The slow student produces a nominal action chunk and compact semantic intent. The fast student retains access to live high-frequency force/torque measurements and predicts only an additive correction conditioned on the current nominal action, robot state, and cached intent. At deployment, the teacher and learned null token are removed, while the two students execute asynchronously. FoRe-VLA thus uses null conditioning only to construct supervision; it does not target force-free deployment or missing-sensor robustness.

Our contributions are:
\begin{enumerate}

    \item a learned null-force conditioning mechanism that creates a non-force-conditioned reference from a frozen force-aware teacher without treating physical zero force as missing input;
    \item a paired full/null teacher-differencing objective that derives explicit nominal and force-conditioned residual targets from demonstrations containing synchronized force measurements;
    \item a nominal--residual distillation framework whose deployed fast student retains live force input and provides asynchronous contact correction alongside a semantic VLA policy.

\end{enumerate}
