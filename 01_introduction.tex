Force-aware Vision-Language-Action (VLA) policies improve contact-rich manipulation by conditioning action generation on interaction feedback~\cite{yu2025forcevlaenhancingvlamodels,li2026forcevla2unleashinghybridforceposition,zhang2025tavlaelucidatingdesignspace}. Yet they typically represent task-level motion and contact-dependent adjustment within the same generative action prediction. At deployment, task-level behavior can be reused across nearby control cycles, whereas physical correction should adapt to newly observed contact. This coupling leaves the correction without an explicit supervision target or an independently executable output (Fig.~\ref{fig:teaser}).

An additive force-responsive residual provides an explicit pose-space correction while retaining the task-level behavior of a missing-force reference. Standard offline demonstrations provide only the executed action: many reference--residual pairs can reconstruct the same label, so direct action supervision does not identify which component should carry task motion and which should carry contact-dependent adjustment.

Subtracting a cached reference from the demonstrated action further mixes force-conditioned deviation with reference staleness. A measured zero wrench is a valid physical condition and must remain distinct from intentionally withholding the wrench history. These ambiguities motivate constructing the correction target from a frozen force-aware teacher under matched query conditions.

Existing asynchronous policies separate computation or sensor-update rates~\cite{li2026favlaforceadaptivefastslowvla,wang2026lateforceacceleratingvla,vanjani2026damvladecoupledasynchronousmultimodal}, while residual reinforcement learning and corrective imitation obtain correction signals from task rewards or additional on-policy interaction~\cite{ankile2024imitationrefinementresidual,xu2025compliantresidualdaggerimproving}. Our objective is complementary: construct correction supervision offline while retaining asynchronous execution.

ForceDelta-VLA constructs both targets under the cached context available to the fast pathway. For an active reference query, matched force-conditioned and missing-force teacher queries reuse its visual--language prefix and flow noise while updating the robot state and force history. Their action difference defines a teacher-supervised force-responsive deviation, and a separate target accounts for reference-state and timing mismatch. The two corrections are distilled into a residual policy that executes independently of generative action inference.

We evaluate ForceDelta-VLA on five single-arm and four bimanual real-robot tasks spanning contact establishment, precision insertion, friction-dominated motion, and constrained manipulation. The proposed method achieves an $82.2\%$ mean success rate, compared with $54.4\%$ for ForceVLA and $72.8\%$ for ImplicitRDP, while reducing peak contact force by approximately $16\%$ and $19\%$ on the single-arm and bimanual platforms, respectively.

The contributions of this work are:
\begin{enumerate}
    \item We introduce \textbf{missing-force residual distillation}, which constructs an explicit teacher-defined force-responsive correction target from matched force-conditioned and learned missing-force predictions of a frozen force-aware teacher, without task rewards, on-policy corrective rollouts, or additional demonstrations beyond the original offline dataset;
    \item We formulate a \textbf{reference-state-consistent dual-residual decomposition} that separately supervises force-conditioned correction and cached-reference staleness, preventing temporal reference mismatch from being absorbed into the force residual; and
    \item We develop an \textbf{independently executable residual pathway} that updates pose corrections from recent force history while reusing cached task context and missing-force references.
\end{enumerate}
