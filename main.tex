\begin{abstract}
Force feedback reveals contact dynamics that may be unobservable in images, yet force-aware Vision-Language-Action (VLA) policies remain costly to update because their reactive pathway regenerates complete action chunks. We introduce ForceDelta-VLA, which replaces full-action regeneration with \emph{counterfactual residual distillation}. After training, a temporal force-aware teacher is frozen and queried twice for the same visual observation, instruction, and robot state: a factual query uses the measured force history, while a counterfactual query uses an adapted null-force mode. Sharing the visual--language prefix and initial flow noise reduces variation unrelated to the conditioning mode, and the pose difference between the predictions defines an explicit target for force-responsive correction. The null-mode prediction supplies a slow reference, while a lightweight causal student combines native-rate force history, cached task context, robot state, and the current reference to predict only the pose residual. We evaluate ForceDelta-VLA on eight single-arm and bimanual contact-rich tasks using task success rate, peak contact force, and task completion time.
\end{abstract}
