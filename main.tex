\begin{abstract}
Force feedback reveals contact dynamics that may be unobservable in images, yet existing force-aware Vision-Language-Action (VLA) policies re-invoke a complete action generator whenever physical feedback is updated. We introduce ForceDelta-VLA, which replaces reactive full-action prediction with \emph{counterfactual residual distillation}. After training, a temporal force-aware teacher is frozen and queried twice for the same visual observation, instruction, and robot state: a factual query uses the measured force history, while a counterfactual query uses an adapted null-force mode. The queries share their visual--language prefix and initial flow noise, and their pose difference defines an explicit target for force-responsive correction. The null-mode prediction supplies a reference, while a lightweight causal student combines a timestamped force history, cached task context, robot state, and the current reference to predict only the pose residual. We evaluate ForceDelta-VLA on eight single-arm and bimanual contact-rich tasks using task success rate, peak contact force, and task completion time.
\end{abstract}
