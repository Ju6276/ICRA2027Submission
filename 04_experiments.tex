\subsection{Experimental Objectives}
\label{sec:exp_objectives}

Our evaluation is designed to answer four questions. First, does native-rate temporal force history improve the unified teacher over instantaneous or visually synchronized force input? Second, does the learned null-force condition produce a useful behavioral decomposition into nominal and force-conditioned components? Third, can the distilled slow--fast students preserve the teacher's task performance while improving contact responsiveness? Finally, which architectural inputs and loss terms are necessary for the fast branch to learn corrective rather than redundant nominal behavior?

\subsection{Tasks and Evaluation Protocol}
\label{sec:exp_protocol}

We evaluate on contact-rich manipulation tasks that require both semantic task progression and rapid physical adaptation. The benchmark should cover four complementary interaction regimes: contact establishment, constrained motion along a surface or mechanism, precision insertion or assembly, and recovery from externally induced disturbances. For every task, training demonstrations contain synchronized multi-view visual observations, language instructions, robot states, commanded actions, and timestamped six-axis force/torque measurements. Force is retained at its native sensing rate; visual and policy observations keep their original timestamps.

\subsection{Baselines and Metrics}
\label{sec:exp_baselines}

We compare the following policy families:
\begin{enumerate}
    \item \textbf{Vision--language nominal policy:} a non-force VLA executed without a fast residual branch;
    \item \textbf{Instantaneous-force VLA:} the ForceVLA teacher using only the force observation aligned with the current visual frame;
    \item \textbf{Temporal force-aware teacher:} our unified teacher with the causal temporal force encoder;
    \item \textbf{Direct slow--fast behavior cloning:} the same student architecture trained only from final demonstrated actions, without teacher-guided nominal--residual targets;
    \item \textbf{FoRe-VLA:} the complete teacher-guided force-residual distillation and asynchronous execution framework.
\end{enumerate}

Task performance is measured by task success rate and, where applicable, stage-wise completion rate. Physical interaction quality is measured using peak force, force impulse, contact-limit violations, and recovery success after a disturbance. To evaluate the decomposition itself, we report the nominal imitation error $d(A^{\mathrm{ref}},A_T^{\mathrm{null}})$, residual imitation error $d(\Delta A,\Delta A_T^F)$, and composed action error $d(A^{\mathrm{ref}}+\Delta A,A_T^{\mathrm{full}})$. Runtime metrics include slow-policy frequency, fast-policy frequency, end-to-end action latency, and parameter count.

\subsection{Analysis of Teacher-Guided Decomposition}
\label{sec:exp_decomposition}

We directly inspect the paired teacher predictions used to construct the distillation targets. For each trajectory, we plot the magnitude of $\Delta A_T^F=A_T^{\mathrm{full}}-A_T^{\mathrm{null}}$ together with measured force and task phase. A useful decomposition should yield small residuals during unconstrained nominal motion and larger, structured corrections near contact onset, force transients, and recovery events. We additionally compare the learned null-force token with two alternatives: a zero force vector and random force-token masking. This experiment tests whether learned null conditioning provides a useful non-force-conditioned reference rather than an out-of-distribution physical zero. It does not treat the output difference as causal force attribution.

\subsection{Ablation Studies}
\label{sec:exp_ablation}

We perform four groups of ablations:
\begin{enumerate}
    \item \textbf{Temporal force representation:} instantaneous force, force history downsampled to the visual rate, and native-rate causal force history;
    \item \textbf{Decomposition strategy:} no decomposition, zero-force subtraction, learned null-force subtraction, and the complete frozen-teacher adaptation;
    \item \textbf{Fast-policy context:} removing slow-policy intent, current robot state, nominal reference action, or the multi-token force sequence;
    \item \textbf{Training objective:} removing $\mathcal{L}_{\mathrm{nom}}$, $\mathcal{L}_{\mathrm{res}}$, $\mathcal{L}_{\mathrm{comp}}$, or $\mathcal{L}_{\mathrm{BC}}$ individually.
\end{enumerate}

\subsection{Asynchronous Execution and Disturbance Recovery}
\label{sec:exp_async}

To isolate the benefit of multi-rate execution, we replay matched contact events under three deployment settings: slow policy only, slow and fast policies synchronized at the VLA rate, and the complete asynchronous controller. We measure the delay from a detected force change to the first corrective command, the maximum force reached before recovery, and the time required to return to the nominal trajectory. These measurements test whether the fast branch provides a genuine control advantage beyond architectural capacity or additional force input.
