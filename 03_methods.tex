\subsection{Problem Formulation}
\label{sec:problem}

We consider an offline dataset $\mathcal D$ of teleoperated manipulation trajectories. At time $t$, each trajectory provides visual observations $V_t$, a language instruction $L$, robot state $S_t$, demonstrated action $A_t^*$, and the causal wrench history
\begin{equation*}
    \mathcal F_t=\{(s,\mathbf w(s))\mid t-T_F\leq s\leq t\},
\end{equation*}
where $T_F$ is the history duration and $\mathbf w(s)=[\mathbf f(s);\boldsymbol\tau(s)]\in\mathbb R^6$ is the per-arm external end-effector wrench. Pose actions and wrench measurements use the corresponding robot-base frame. A force-conditioned teacher $T_\theta$ maps $(V_t,L,S_t,\mathcal F_t)$ to an $H$-step action chunk relative to $S_t$. Pose actions and residuals below use its normalized pose-action coordinates, with differences scaled by the action standard deviations.

Let $\mathcal P(\cdot)$ extract the pose component of an action. We decompose the commanded pose into a reference, two learned corrections, and a deterministic rebasing term,
\begin{equation}
    \mathcal P(A^{\mathrm{cmd}})
    =\mathcal P(A^{\mathrm{ref}})
      +\Delta\hat A^{\mathrm{force}}
      +\Delta\hat A^{\mathrm{stale}}
      +\Gamma(S_t,S_k).
    \label{eq:action_comp}
\end{equation}
The force residual models the teacher's force-conditioning deviation, the learned staleness residual models the remaining cached-reference discrepancy, and $\Gamma$ rebases the reference query state $S_k$ to the current state $S_t$. All three terms modify only pose; the gripper command is inherited from the reference.

Here $\mathcal P(A)=[p;r]$ contains translation $p\in\mathbb R^3$ and a continuous 6D rotation representation $r\in\mathbb R^6$~\cite{zhou2020continuityrotationrepresentationsneural}. Translation is added directly; rotational corrections are added in the teacher's 6D action coordinates and mapped to a valid rotation matrix by Gram--Schmidt orthogonalization. On the bimanual platform, $\mathcal P(A)$, $S_t$, and $\mathcal F_t$ concatenate the corresponding per-arm quantities, so the pose-action dimension doubles and a single residual query predicts both arms jointly. All residual operations, including the coordinate rebasing of Sec.~\ref{sec:teacher_differencing} and the deployment bounds of Sec.~\ref{sec:execution}, act component-wise over the concatenated pose vector under a shared bound rather than per-arm bounds.

\subsection{Method Overview}
\label{sec:method_overview}

Training proceeds in three stages (Fig.~\ref{fig:network_structure}). First, we train a temporal force-conditioned VLA teacher. Second, we freeze the teacher and learn a missing-force mode that supplies the reference action. Third, we freeze both modes, construct cached-context force and staleness targets, and train the residual policy.

\subsection{Force-Conditioned Teacher and Missing-Force Reference}
\label{sec:teacher_and_missing}

\subsubsection{Temporal force-conditioned teacher}

We build $T_\theta$ on ForceVLA~\cite{yu2025forcevlaenhancingvlamodels} and replace its instantaneous force embedding with the causal temporal encoding
\begin{equation}
    z_t^F=E_T^F(\mathcal F_t).
    \label{eq:teacher_tcn}
\end{equation}
The teacher is trained on $\mathcal D$ to predict
\begin{equation}
    A_{T,t,1:H}^{\mathrm{cond}}
    =T_\theta(V_t,L,S_t,z_t^F;\epsilon),
    \label{eq:conditioned_teacher}
\end{equation}
where $\epsilon$ is the initial flow noise. We freeze $\theta$ after training.

\subsubsection{Missing-force reference mode}

We distinguish an unavailable wrench history from a physically measured zero wrench. The learned missing-force mode represents the former and comprises a missing-force token $z_{\varnothing F}$ and a rank-$\rho$ adapter $\phi=\{z_{\varnothing F},W_{\mathrm{in}},W_{\mathrm{out}}\}$. The adapter modifies the pose channels of the action expert,
\begin{equation}
    v^p\leftarrow v^p+W_{\mathrm{out}}\,
    \sigma(W_{\mathrm{in}}h),
    \label{eq:missing_force_adapter}
\end{equation}
where $h$ is an action-expert hidden state, $v^p$ its pose-channel flow output, and $\sigma$ a pointwise nonlinearity. The adapter is active only in the missing-force mode. With $\theta$ fixed, optimizing $\phi$ under the teacher's original flow-matching objective defines the missing-force operating point.
The resulting reference prediction is
\begin{equation}
    A_{T,t,1:H}^{\mathrm{miss}}
    =T_{\theta,\phi}^{\mathrm{miss}}
      (V_t,L,S_t,z_{\varnothing F};\epsilon).
    \label{eq:teacher_missing}
\end{equation}

\subsection{Reference-State-Consistent Dual-Residual Distillation}
\label{sec:distillation}

\subsubsection{Correction targets}
\label{sec:teacher_differencing}

For a schedule-replay sample $(t,k)$, let $E_k$ be the visual--language prefix produced when reference query $k$ starts at $t_k$ from $(V_k,L,S_k)$ with flow noise $\epsilon_k$. Its missing-force action chunk defines the timestamped reference, $A_k^{\mathrm{ref}}=A_{T,k}^{\mathrm{miss}}$. To match the information available to the deployed residual pathway, target generation reuses $E_k$ while updating the robot state and force history to time $t$:
\begin{align}
    A_{T,t|k,1:K}^{\mathrm{cond}}
    &=T_\theta(E_k,S_t,z_t^F;\epsilon_k)_{1:K},
    \label{eq:cached_conditioned_teacher}\\
    A_{T,t|k,1:K}^{\mathrm{miss}}
    &=T_{\theta,\phi}^{\mathrm{miss}}
      (E_k,S_t,z_{\varnothing F};\epsilon_k)_{1:K}.
    \label{eq:cached_missing_teacher}
\end{align}
Here $T(E_k,\cdot)$ reuses the cached prefix without encoding a current image. The reference, force-conditioned, and missing-force queries share $E_k$ and $\epsilon_k$. For $j=1,\ldots,K\leq H$, the teacher-defined force-responsive residual target is
\begin{equation}
    \Delta A_{T,t|k,j}^{\mathrm{force}}
    =\mathcal P\!\left(A_{T,t|k,j}^{\mathrm{cond}}\right)
     -\mathcal P\!\left(A_{T,t|k,j}^{\mathrm{miss}}\right),
    \label{eq:force_target}
\end{equation}
which supervises the force-responsive residual head.

The residual query predicts $K$ action samples at $t_j=t+(j-1)/f_A$, where $f_A$ is the action-sample rate within a chunk. Let $\widetilde S^{p}$ denote the normalized pose coordinates (nine per arm), and let $\sigma_S^{p}$ and $\sigma_A^{p}$ denote the corresponding training-set standard deviations. The cached-state gap is converted to normalized action coordinates as
\begin{equation}
    \Gamma(S_t,S_k)
    =\frac{\sigma_S^{p}+\varepsilon}{\sigma_A^{p}+\varepsilon}
      \odot(\widetilde S_t^{p}-\widetilde S_k^{p}),
    \qquad \varepsilon=10^{-6}.
    \label{eq:coordinate_rebasing}
\end{equation}
The learned staleness target is
\begin{equation}
    \Delta A_{T,k\rightarrow t,j}^{\mathrm{stale}}
    =\mathcal P\!\left(A_{T,t|k,j}^{\mathrm{miss}}\right)
      -\mathcal P\!\left(A_k^{\mathrm{ref}}(t_j)\right).
    \label{eq:staleness_target}
\end{equation}
Let $\mathcal R(S,a)$ convert a relative action $a$ based at state $S$ into an absolute robot command. The paired targets align the two coordinate bases stepwise:
\begin{equation}
\begin{aligned}
    &\mathcal R\!\left(S_k,\mathcal P(A_k^{\mathrm{ref}}(t_j))
      +\Delta A_{T,t|k,j}^{\mathrm{force}}
      +\Delta A_{T,k\rightarrow t,j}^{\mathrm{stale}}
      +\Gamma(S_t,S_k)\right)\\[-2pt]
    &\qquad\approx\mathcal R\!\left(S_t,
      \mathcal P(A_{T,t|k,j}^{\mathrm{cond}})\right).
\end{aligned}
    \label{eq:absolute_command_equivalence}
\end{equation}
Substitution leaves the force-conditioned chunk rebased by $\Gamma$. Translational rebasing is exact in normalized Euclidean coordinates up to $\varepsilon$; rotational rebasing uses an additive approximation in the teacher's 6D representation followed by Gram--Schmidt projection. Equation~\eqref{eq:absolute_command_equivalence} therefore describes the unclipped composition and remains approximate for rotation.

\subsubsection{Residual policy}
\label{sec:residual_policy}

Each reference query caches a compact representation of its visual--language context. Let $m_k$ denote the validity mask over tokens in $E_k$ from available image views and non-padding language positions; state, force, and action tokens are excluded from $E_k$. We compress the prefix in two stages,
\begin{align}
    (\bar E_k,\bar m_k)
    &=\operatorname{Pool}_{M}(E_k,m_k),\nonumber\\
    Z_k^{\mathrm{intent}}
    &=P_{\mathrm{intent}}(\bar E_k,\bar m_k).
    \label{eq:intent_projection}
\end{align}
Here $\operatorname{Pool}_{M}$ partitions the padded prefix into contiguous, approximately equal-width positional bins and applies masked mean pooling within each bin, retaining the bin-validity mask $\bar m_k$. The projector $P_{\mathrm{intent}}$ uses $Q$ learned queries to aggregate the valid pooled tokens. We use $M=16$ bins and $Q=2$ learned queries.
The intent tokens represent the visual--language task context available when reference query $k$ starts.
Together, $A_k^{\mathrm{ref}}$, $Z_k^{\mathrm{intent}}$, and $S_k$ form the timestamped reference update for query $k$; the latest available update is cached for the fast pathway. The residual treats this context as locally valid within a reference interval. Timestamp-based interpolation provides $A_k^{\mathrm{ref}}(t)$. A causal encoder maps $\mathcal F_t$ to $u_t^F$. Cache age and interpolation phase are encoded as
\begin{equation}
    \xi_{t,k}=
    \left[\min\!\left(\frac{t-t_k}{c},1\right);\alpha_{t,k}\right],
    \label{eq:time_features}
\end{equation}
where $c$ is an age scale and $\alpha_{t,k}$ is the position of $t$ between adjacent reference samples. The conditioning set is
\begin{align}
    \mathcal C_t=[&P_Z(Z_k^{\mathrm{intent}});u_t^F;P_S(S_t);
    \nonumber\\[-2pt]
    &P_A(A_k^{\mathrm{ref}}(t));P_\xi(\xi_{t,k})].
    \label{eq:conditioning_set}
\end{align}
Here $P_Z,P_A,P_S$, and $P_\xi$ project to the shared token width. There is no positional encoding: a learned type embedding identifies each condition, so $\Phi$ is invariant to the order of $\mathcal C_t$. $\Gamma(S_t,S_k)$ is computed outside the policy and is omitted from $\mathcal C_t$. Let $\mathcal C_t^{\mathrm{maskF}}=\operatorname{Mask}_F(\mathcal C_t)$ be the same set with the force token masked.

An attention block $\Phi$ and learned query $q_{\mathrm{res}}$ predict two $K$-step corrections,
\begin{align}
    \Delta\hat A^{\mathrm{force}}_{t,1:K}
    &=W_{\mathrm{force}}\Phi([\mathcal C_t;q_{\mathrm{res}}])[q_{\mathrm{res}}],
    \label{eq:force_output}\\
    \Delta\hat A^{\mathrm{stale}}_{t,1:K}
    &=W_{\mathrm{stale}}
      \Phi([\mathcal C_t^{\mathrm{maskF}};q_{\mathrm{res}}])[q_{\mathrm{res}}].
    \label{eq:staleness_output}
\end{align}
The mask prevents direct dependence of the staleness output on the force token. The two passes share $\Phi$ and use separate output projections.

\subsubsection{Asynchronous schedule replay}
\label{sec:async_training}

We sample an asynchronous schedule before cached-context target extraction and replay the resulting fixed schedule during residual-policy optimization. The schedule specifies inter-query periods and reference-query latencies. Training instants follow the recorded state--action timestamps, while $\mathcal F_t$ retains all wrench samples in the causal window. If $t_i$ and $\bar t_i$ are the start and availability times of query $i$, the active reference index is
\begin{equation*}
    k(t)=\arg\max_{i:\bar t_i\leq t}t_i.
\end{equation*}
The active reference update supplies the cached intent, current reference sample, and timestamps used to compute the temporal features and stepwise targets. The schedule determines the reference age, interpolation phase, and reference-query latency represented during optimization.

With normalized temporal weights $w_j\propto\beta^{j-1}$, $0<\beta\leq1$, and normalized-coordinate mean-squared loss $\ell_{\mathrm{pose}}$, the distillation objective is
\begin{align}
    \mathcal L_{\mathrm{distill}}=\sum_{j=1}^{K}w_j\big[&
      \ell_{\mathrm{pose}}(\Delta\hat A^{\mathrm{force}}_{t,j},
        \Delta A^{\mathrm{force}}_{T,t|k,j})
    \nonumber\\[-2pt]
      &+\lambda_{\mathrm{stale}}
        \ell_{\mathrm{pose}}(\Delta\hat A^{\mathrm{stale}}_{t,j},
        \Delta A^{\mathrm{stale}}_{T,k\rightarrow t,j})\big].
    \label{eq:res_loss}
\end{align}
The coefficient $\lambda_{\mathrm{stale}}$ balances force-conditioning and staleness supervision.

\subsection{Independent Residual Execution}
\label{sec:execution}

The reference and residual workers execute independently (Fig.~\ref{fig:async_deployment}). Each residual query reads the active reference update with the current state and $\mathcal F_t$. Its $K$-step correction chunk stays bound to that update, so a newly available reference is used only by later residual queries.

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{figures/fig03_async_deployment.pdf}
    \caption{Three-lane timeline of independent residual execution. A reference query spans its start $t_k$ and its availability $\bar t_k$. Each residual query binds to the reference available at that instant and emits one $K$-step correction chunk, and fill color carries that binding to the command steps. The chunk queried before $\bar t_k$ keeps reference $k{-}1$ for all of its steps, including the two executed after $\bar t_k$ (dashed), so reference $k$ is first used by the following chunk.}
    \label{fig:async_deployment}
\end{figure}

Expired correction steps are skipped, and the remaining steps execute sequentially without interpolation. The reference pose is interpolated by timestamp. At each update, $\Gamma(S_t,S_k)$ is computed directly from the current and cached query states. The force residual is bounded independently; the sum $\Delta\hat A^{\mathrm{stale}}+\Gamma(S_t,S_k)$ is bounded as the staleness correction. Both are composed with the reference in normalized delta-action coordinates and converted to an absolute command using the reference query state.
