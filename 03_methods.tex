\subsection{Problem Formulation}
\label{sec:problem}

We consider an offline dataset $\mathcal D$ of teleoperated manipulation trajectories. Each trajectory contains visual observations $V_t$, a language instruction $L$, robot state $S_t$, timestamped force/torque history $\mathcal F_t$, and demonstrated action $A_t^*$. Here $\mathcal F_t$ is the six-axis estimate of external forces and torques acting at the end effector. A force-conditioned VLA teacher $T_\theta$ maps these observations to an $H$-step action chunk.

We seek both an identifiable force-responsive correction target and a deployment decomposition in which that correction can be updated independently of the reference generator. The decomposition comprises a reference generator that captures task-level motion and a residual policy $\pi_\psi$ that updates pose corrections from recent force feedback. Let $\mathcal P(\cdot)$ extract the end-effector pose component of an action, concatenated across arms for bimanual tasks. If $k$ indexes the latest completed reference query, issued at $t_k$ from state $S_k$, the command at control time $t>t_k$ is
\begin{align}
    \mathcal P(A^{\mathrm{cmd}}(t))
    &=\mathcal P(A^{\mathrm{ref}}(t))
      +\Delta\hat A^{\mathrm{force}}(t)
      +\Delta\hat A^{\mathrm{stale}}(t),
      \label{eq:action_comp_pose}\\
    g^{\mathrm{cmd}}(t)&=g^{\mathrm{ref}}(t).
    \label{eq:action_comp}
\end{align}
The force term captures the teacher's response to current force conditioning, while the staleness term aligns the cached reference with the current state and nominal prediction. Demonstrations supervise only $A_t^*$ and do not specify this decomposition. The central problem is therefore to construct explicit targets for both corrections from the pretrained force-aware policy.

Equation~\eqref{eq:action_comp_pose} uses representation-space addition. For each arm, $\mathcal P(A)=[p;r]$ contains translation $p\in\mathbb R^3$ and the continuous 6D rotation representation $r\in\mathbb R^6$. Translation is added directly. For rotation, we form
\begin{equation*}
    \tilde r^{\mathrm{cmd}}
    =r^{\mathrm{ref}}+\Delta r^{\mathrm{force}}
     +\Delta r^{\mathrm{stale}},\qquad
    R^{\mathrm{cmd}}=\operatorname{GS}(\tilde r^{\mathrm{cmd}}),
\end{equation*}
where $\operatorname{GS}$ orthogonalizes the two represented rotation columns. This is an additive correction in the teacher's action representation, not rotation composition on $SO(3)$.

\subsection{Method Overview}
\label{sec:method_overview}

ForceDelta-VLA is trained in three stages (Fig.~\ref{fig:network_structure}). First, we train a temporal force-conditioned VLA teacher. Second, with the teacher frozen, we learn a null-force operating mode whose prediction supplies the reference action. Third, we construct force-conditioning and staleness targets from frozen teacher predictions and distill them into the residual policy.

Beyond target construction, deployment instantiates the decomposition as two independently scheduled pathways. The reference worker publishes timestamped null-mode action chunks and cached task context, while the residual worker combines that packet with the latest force history and robot state to update pose corrections without invoking full-action generation.

\subsection{Force-Conditioned Teacher and Null Reference}
\label{sec:teacher_and_null}

\subsubsection{Temporal force-conditioned teacher}

We build $T_\theta$ on ForceVLA~\cite{yu2025forcevlaenhancingvlamodels} and replace its instantaneous force input with a causal temporal encoder. For a fixed window duration $w$,
\begin{equation}
    z_t^F=E_T^F\!\left(\{F(\tau)\mid t-w\leq\tau\leq t\}\right).
    \label{eq:teacher_tcn}
\end{equation}
The encoder output replaces the original force embedding; the remaining action generator is unchanged. The teacher is fully fine-tuned on $\mathcal D$ to predict
\begin{equation}
    A_{T,t}^{\mathrm{full}}
    =T_\theta(V_t,L,S_t,z_t^F;\epsilon),
    \label{eq:full_teacher}
\end{equation}
where $\epsilon$ is the initial flow noise. We freeze $\theta$ after training.

\subsubsection{Null-force reference mode}

Zero force is a valid physical measurement and therefore does not represent the absence of a force history. We introduce a learned null token $z_{\varnothing F}$ and a rank-$\rho$ adapter $\phi=\{z_{\varnothing F},W_{\mathrm{in}},W_{\mathrm{out}}\}$. The adapter modifies the pose channels of the action expert,
\begin{equation}
    v^p\leftarrow v^p+W_{\mathrm{out}}\,
    \sigma(W_{\mathrm{in}}h),
    \label{eq:nominal_adapter}
\end{equation}
and is active only in the null mode. With $\theta$ fixed, $\phi$ is optimized using the original flow-matching objective,
\begin{equation}
    \mathcal L_{\mathrm{null}}
    =\mathbb E_{\mathcal D,\tau,\epsilon}
      \!\left[\ell_{\mathrm{FM}}\!\left(
      T_{\theta,\phi}^{\mathrm{null}},
      A_{t:t+H-1}^*;\tau,\epsilon\right)\right].
    \label{eq:null_training}
\end{equation}
Because only the null-mode parameters $\phi$ are optimized under the original imitation objective while the force-conditioned teacher remains frozen, the null mode defines a force-input-agnostic operating point of the teacher rather than an independently optimized task policy.
The resulting reference prediction is
\begin{equation}
    A_{T,t}^{\mathrm{null}}
    =T_{\theta,\phi}^{\mathrm{null}}
      (V_t,L,S_t,z_{\varnothing F};\epsilon).
    \label{eq:teacher_null}
\end{equation}

\subsection{Null-Mode Residual Distillation}
\label{sec:distillation}

\subsubsection{Paired correction targets}
\label{sec:teacher_differencing}

For the same $(V_t,L,S_t)$, the full-force and null-force queries reuse the visual--language prefix and the initial noise $\epsilon$. Their pose difference defines the teacher-level force-conditioning deviation,
\begin{equation}
    \Delta A_{T,t}^{\mathrm{force}}
    =\mathcal P\!\left(A_{T,t}^{\mathrm{full}}\right)
     -\mathcal P\!\left(A_{T,t}^{\mathrm{null}}\right).
    \label{eq:force_target}
\end{equation}
This target measures the output difference between two learned operating modes of the teacher and provides explicit supervision for the force-responsive residual.

At deployment, the active reference was generated by query $k$ from state $S_k$, whereas the current null-mode prediction is relative to $S_t$. End-effector positions and 6D orientation features are expressed in the corresponding arm's robot-base frame. Let $\Gamma(S_t,S_k)$ map the state displacement from $S_k$ to $S_t$ into the same normalized pose-action coordinates as $\mathcal P(A)$. A cached relative action is rebased to the current state as
\begin{equation*}
    \mathcal P(A^{\mathrm{ref}}_{k\rightarrow t})
    =\mathcal P(A^{\mathrm{ref}}(t))-\Gamma(S_t,S_k).
\end{equation*}
Its discrepancy from the current null-mode prediction therefore defines the staleness target,
\begin{equation}
    \Delta A_{T,t}^{\mathrm{stale}}
    =\mathcal P\!\left(A_{T,t}^{\mathrm{null}}\right)
     -\mathcal P\!\left(A^{\mathrm{ref}}(t)\right)
     +\Gamma(S_t,S_k).
    \label{eq:staleness_target}
\end{equation}
The positive sign on $\Gamma$ follows from subtracting the rebased reference: $A^{\mathrm{null}}_{T,t}-A^{\mathrm{ref}}_{k\rightarrow t}=A^{\mathrm{null}}_{T,t}-A^{\mathrm{ref}}+\Gamma$. The sum of Eqs.~\eqref{eq:force_target} and~\eqref{eq:staleness_target} is consequently the pose correction required to match the current full-force teacher prediction.

\subsubsection{Residual policy}
\label{sec:residual_policy}

Each completed reference query also publishes a compact task representation. Given visual--language prefix $E_k\in\mathbb R^{L\times d}$ and mask $m_k$, we pool contiguous token groups into $M$ intent tokens,
\begin{equation}
    Z_k^{\mathrm{intent}}
    =\operatorname{Pool}_M(E_k,m_k)
    \in\mathbb R^{M\times d}.
    \label{eq:intent_projection}
\end{equation}
A student-specific causal encoder maps the latest force history to $u_t^F$. We additionally encode the cache age and the interpolation phase,
\begin{equation}
    \xi_{t,k}=
    \left[\min\!\left(\frac{t-t_k}{c},1\right);\alpha_{t,k}\right],
    \label{eq:time_features}
\end{equation}
where $c$ is an age scale and $\alpha_{t,k}$ is the position of $t$ between adjacent reference samples. The conditioning set is
\begin{align}
    \mathcal C_t=\{&P_Z(Z_k^{\mathrm{intent}}),u_t^F,P_S(S_t),
    \nonumber\\[-2pt]
    &P_A(A^{\mathrm{ref}}(t)),P_\xi(\xi_{t,k})\}.
    \label{eq:conditioning_set}
\end{align}

An attention block $\Phi$ and learned query $q$ predict two $K$-step corrections,
\begin{align}
    \Delta\hat A^{\mathrm{force}}_{t,1:K}
    &=W_{\mathrm{force}}\Phi(\mathcal C_t\cup\{q\})[q],
    \label{eq:force_output}\\
    \Delta\hat A^{\mathrm{stale}}_{t,1:K}
    &=W_{\mathrm{stale}}
      \Phi((\mathcal C_t\setminus\{u_t^F\})\cup\{q\})[q].
    \label{eq:staleness_output}
\end{align}
Both outputs lie in the pose-action space defined by $\mathcal P$. Masking the force token in the second pass prevents direct force dependence in the staleness output. The passes share $\Phi$ and use separate zero-initialized output projections.

\subsubsection{Staleness-aware schedule replay}
\label{sec:async_training}

We reproduce the deployment schedule offline. For each control instant $t$, the sampled slow-update period and query latency determine the latest completed query $k$. The student receives $Z_k^{\mathrm{intent}}$ and $A^{\mathrm{ref}}(t)$ from that query, together with $\mathcal F_t$, $S_t$, and $\xi_{t,k}$ from the current instant. Both targets are evaluated at $t$ from precomputed frozen-teacher outputs. Resampling the update period and latency exposes the student to a distribution of cache ages.

With normalized weights $w_j\propto\beta^{j-1}$ and pose-space loss $d$, the distillation objective is
\begin{align}
    \mathcal L=\sum_{j=1}^{K}w_j\big[&
      d(\Delta\hat A^{\mathrm{force}}_{t,j},
        \Delta A^{\mathrm{force}}_{T,t,j})
    \nonumber\\[-2pt]
      &+\lambda d(\Delta\hat A^{\mathrm{stale}}_{t,j},
        \Delta A^{\mathrm{stale}}_{T,t,j})\big].
    \label{eq:res_loss}
\end{align}

\subsection{Independent Residual Execution}
\label{sec:execution}

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{figures/fig03_async_deployment.pdf}
    \caption{Independent residual execution. The reference worker publishes timestamped null-mode actions and cached task context; the residual worker continues updating from current force and state while a new reference query is pending.}
    \label{fig:async_deployment}
\end{figure}

The reference and residual workers execute independently (Fig.~\ref{fig:async_deployment}). A query issued at $t_k$ publishes $(A_{T,k}^{\mathrm{null}},Z_k^{\mathrm{intent}},S_k)$ when it completes at $\bar t_k$. Reference samples have timestamps
\begin{equation}
    \tau_{k,j}=t_k+(j-1)/f_A,
    \qquad j=1,\ldots,H.
    \label{eq:reference_timestamps}
\end{equation}
Samples with $\tau_{k,j}<\bar t_k$ are discarded, and $A^{\mathrm{ref}}(t)$ is interpolated from the remaining samples. Until a newer query completes, the residual worker uses the latest published packet with current $(\mathcal F_t,S_t)$ to evaluate Eqs.~\eqref{eq:force_output}--\eqref{eq:staleness_output}. The selected corrections are bounded separately and composed according to Eq.~\eqref{eq:action_comp}; the reference supplies the gripper command.
