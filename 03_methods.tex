\subsection{Problem Formulation}
\label{sec:problem}

We are given a dataset $\mathcal{D}$ of teleoperated contact-rich manipulation trajectories. At time $t$, each trajectory provides visual observations $V_t$, a language instruction $L$, robot state $S_t$, a timestamped force/torque history $\mathcal{F}_t$, and the demonstrated action $A_t^*$. An action is represented as
\begin{equation}
    A=[\,p\in\mathbb{R}^{3};\;r\in\mathbb{R}^{6};\;g\in\mathbb{R}\,]
    \in\mathbb{R}^{10},
    \label{eq:action_space}
\end{equation}
where $p$ is translation, $r$ is a continuous 6D rotation representation~\cite{zhou2019continuity}, and $g$ is the gripper command. We denote the pose component by $A^p=[p;r]\in\mathbb{R}^{9}$.

Let $T_\theta$ denote a force-conditioned VLA trained on $\mathcal{D}$ to predict an $H$-step action chunk. Our goal is to derive from $T_\theta$ a factorized policy with two components: a reference action $A^{\mathrm{ref}}$ that carries task-level motion, and a residual policy $\pi_\psi^\Delta$ that predicts pose corrections from the latest force history and cached task context. Specifically,
\begin{align}
    \Delta\hat A(t)
    &=\pi_\psi^\Delta(\mathcal{F}_t,S_t,A^{\mathrm{ref}}(t),Z^{\mathrm{intent}}),\\
    (A^{\mathrm{cmd}}(t))^p
    &=(A^{\mathrm{ref}}(t))^p+\Delta\hat A(t),
    \qquad g^{\mathrm{cmd}}(t)=g^{\mathrm{ref}}(t).
    \label{eq:action_comp}
\end{align}
The demonstrations supervise only $A_t^*$; they contain no labels for $A^{\mathrm{ref}}$ or the residual correction. The learning problem is therefore to construct a correction target from $\mathcal{D}$ and the trained teacher, and to learn $\pi_\psi^\Delta$ without task rewards or additional corrective demonstrations.

ForceDelta-VLA addresses this problem through the three-stage procedure summarized in Fig.~\ref{fig:network_structure}. We first train a temporal force-conditioned teacher. We then freeze the teacher and learn a null-force reference mode. Finally, we freeze both teacher modes, construct paired residual targets, and distill them into a compact residual policy.

\subsection{Temporal Force-Conditioned Teacher}
\label{sec:teacher}

We build the teacher on ForceVLA~\cite{yu2025forcevla}, replacing its instantaneous force input with a causal temporal encoder. At inference time $t_k$, the encoder receives a fixed-duration window from the native-rate force stream,
\begin{equation}
    \mathcal{F}_k=\{F(\tau)\mid t_k-w\leq\tau\leq t_k\},
    \label{eq:force_window}
\end{equation}
together with a validity mask for samples unavailable at the beginning of a trajectory. A causal temporal convolutional network produces
\begin{equation}
    z_k^F=E_T^F(\mathcal{F}_k),
    \label{eq:teacher_tcn}
\end{equation}
which replaces the original force embedding in the multimodal fusion module. The remaining action-generation architecture is unchanged. The teacher is fully fine-tuned on the demonstrations to predict
\begin{equation}
    A_{T,k}^{\mathrm{full}}
    =T_\theta(V_k,L,S_k,z_k^F;\epsilon)
    \in\mathbb{R}^{H\times10},
    \label{eq:full_teacher}
\end{equation}
where $\epsilon$ is the initial noise of the flow-matching action generator. After this stage, $\theta$ is fixed.

\subsection{Learning the Null-Force Reference}
\label{sec:null_decomp}

The residual target should describe how the force-conditioned teacher changes its prediction relative to a valid reference policy. Simply setting force to zero is unsuitable for this purpose: zero is a physically meaningful measurement and does not explicitly denote an unavailable force condition. We instead learn a null-force mode and compare it with the teacher's factual-force mode under matched sampling conditions.

The null mode comprises a learned token $z_{\varnothing F}$ and a lightweight null-specific adapter. These are distinct components trained jointly in the same stage: the token represents the absence of an instance-specific force history, while the adapter restores action prediction under that condition. Let
$\phi=\{z_{\varnothing F},W_{\mathrm{in}},W_{\mathrm{out}}\}$.
The adapter modifies only the pose channels of the action expert,
\begin{equation}
    v^p\leftarrow v^p+W_{\mathrm{out}}\,
    \sigma(W_{\mathrm{in}}h),
    \label{eq:nominal_adapter}
\end{equation}
where $h$ is the action-expert hidden state and the adapter has rank $\rho$. With $\theta$ fixed, $\phi$ is optimized using the teacher's flow-matching objective,
\begin{equation}
    \mathcal{L}_{\mathrm{null}}
    =\mathbb{E}_{\mathcal{D},\tau,\epsilon}
      \left[\ell_{\mathrm{FM}}\!\left(
      T_{\theta,\phi}^{\mathrm{null}},
      A_{k:k+H-1}^{*};\tau,\epsilon\right)\right].
    \label{eq:null_training}
\end{equation}
The adapter is enabled only in the null mode; the factual-force mode retains the trained teacher parameters and computation. The resulting null-mode prediction serves as the slowly updated reference at deployment.

\subsection{Counterfactual Residual Distillation}

\subsubsection{Paired Target Construction}
\label{sec:teacher_differencing}

Because the teacher uses flow matching, independently sampled predictions contain variation unrelated to the conditioning mode. For each training sample, we therefore reuse the visual--language prefix and initialize both predictions with the same noise $\epsilon$:
\begin{align}
    A_{T,k}^{\mathrm{full}}
    &=T_\theta(V_k,L,S_k,z_k^F;\epsilon),
    \label{eq:teacher_full_again}\\
    A_{T,k}^{\mathrm{null}}
    &=T_{\theta,\phi}^{\mathrm{null}}
      (V_k,L,S_k,z_{\varnothing F};\epsilon),
      \qquad \epsilon\sim\mathcal{N}(0,I).
    \label{eq:teacher_null}
\end{align}
The reference target and pose-residual target are
\begin{align}
    A_{T,k}^{\mathrm{ref}}&=A_{T,k}^{\mathrm{null}},
    \label{eq:nominal_target}\\
    \Delta A_{T,k}^{\mathrm{cf}}
    &=\left(A_{T,k}^{\mathrm{full}}\right)^p
      -\left(A_{T,k}^{\mathrm{null}}\right)^p
      \in\mathbb{R}^{H\times9}.
    \label{eq:teacher_residual}
\end{align}
We refer to Eq.~\eqref{eq:teacher_residual} as a counterfactual residual because it compares two operating modes of the same teacher under matched observations and sampling noise. It is a model-level conditional difference, not a causal attribution of contact: the adapted null mode differs parametrically from the factual mode, and visual observations and robot state may also encode contact information.

\subsubsection{Fast Residual Policy}
\label{sec:residual_policy}

At each slow update, the null-mode teacher publishes the reference chunk $A_{T,k}^{\mathrm{null}}$ and a compact task representation. Given the visual--language prefix $H_k\in\mathbb{R}^{S\times d}$ and its mask $m_k$, we pool contiguous token groups into $M$ intent tokens,
\begin{equation}
    Z_k^{\mathrm{intent}}
    =\mathrm{Pool}_M(H_k,m_k)
    \in\mathbb{R}^{M\times d}.
    \label{eq:intent_projection}
\end{equation}
This representation allows the residual policy to use the teacher's task context without running a second visual--language backbone.

For the current control instant $t$, a causal TCN encodes the latest force window into $Z_t^F$. The residual policy receives
\begin{equation}
    X_t=
    [\,\widetilde Z_k^{\mathrm{intent}};
       Z_t^F;
       P_S(S_t);
       P_A(A^{\mathrm{ref}}(t));
       q\,],
    \label{eq:fast_token_sequence}
\end{equation}
where $P_S$ and $P_A$ are learned projections and $q$ is a learned output query. Type embeddings distinguish the input groups. A compact attention block maps these conditions to a short pose-correction chunk,
\begin{equation}
    \Delta\hat A_{t,1:K}
    =W_{\mathrm{res}}H_t[q]
    \in\mathbb{R}^{K\times9}.
    \label{eq:residual_output}
\end{equation}
The output head is initialized to zero, so the initial student predicts no correction and leaves the reference unchanged.

\subsubsection{Distillation Objective}
\label{sec:loss}

The student is trained on the first $K$ steps of the paired targets. With normalized weights $w_j\propto\beta^{j-1}$ and pose-space regression loss $d$, we minimize
\begin{equation}
    \mathcal{L}_{\mathrm{distill}}
    =\sum_{j=1}^{K}w_j\,
      d\!\left(\Delta\hat A_{k,j},
      \Delta A^{\mathrm{cf}}_{T,k,j}\right).
    \label{eq:res_loss}
\end{equation}
The decaying weights emphasize corrections that are executed earlier in the predicted chunk.

\subsection{Asynchronous Deployment}
\label{sec:execution}

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{figures/fig03_async_deployment.pdf}
    \caption{Asynchronous deployment. The reference and residual workers execute independently. A completed VLA query atomically replaces the timestamped cache; residual updates continue against the latest complete cache while the next VLA query is running.}
    \label{fig:async_deployment}
\end{figure}

Deployment uses two independent workers, as illustrated in Fig.~\ref{fig:async_deployment}. At request time $t_k$, the reference worker snapshots $(V_k,L,S_k)$ and invokes the frozen teacher in its null-force mode. When inference completes at $\bar t_k$, it atomically publishes a versioned packet containing $A_{T,k}^{\mathrm{null}}$, $Z_k^{\mathrm{intent}}$, and the action timestamps. Publishing the packet as one unit prevents the residual worker from combining a reference chunk with intent tokens from different teacher queries.

The reference samples are timestamped relative to the request time at the action rate $f_A$:
\begin{equation}
    \tau_{k,j}=t_k+(j-1)/f_A,\qquad j=1,\ldots,H.
    \label{eq:reference_timestamps}
\end{equation}
Upon publication, samples with $\tau_{k,j}<\bar t_k$ are expired. At a control instant $t$, $A^{\mathrm{ref}}(t)$ is interpolated from the valid samples that bracket $t$; the previously published packet remains active until a newer complete packet becomes available. This alignment prevents inference latency from restarting execution at the beginning of a stale chunk.

The residual worker follows its own schedule and never waits for the reference worker. At each update, it takes a consistent snapshot of the latest packet, reads the most recent force window $\mathcal F_t$ and robot state $S_t$, and predicts $\Delta\hat A_{t,1:K}$ in one deterministic pass. The first correction is composed with the time-aligned reference according to Eq.~\eqref{eq:action_comp}; the reference supplies the gripper command. Consequently, semantic action generation is updated only when a teacher query completes, whereas force-conditioned pose corrections continue to update while the next flow-matching query is in progress.
